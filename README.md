
# 项目：Terminal TUI 编辑器（命令代码编辑器）

## 项目概述
构建一个基于 Ratatui 的终端用户界面（TUI）编辑器，支持三种模式：
- 只读模式（ReadOnly）：浏览内容，不可修改
- 编辑模式（Edit）：自由编辑文本内容
- 命令模式（Command）：在底部命令行输入命令执行操作

## 核心功能需求

### 1. 编辑器模式
- **只读模式**：用户可以浏览文本，光标可移动，但无法修改内容
- **编辑模式**：用户可以插入和删除字符，光标自由移动
- **命令模式**：键盘输入聚焦到底部命令行，支持命令输入和执行

### 2. 界面布局
- **左上角**：显示标题 "Command Code Editor"
- **主体区域**：显示文本内容（可滚动）
- **最底部一行**：命令行输入栏
  - 命令模式下显示光标和输入内容
  - 其他模式下显示当前模式状态（如 `-- 只读模式 --`）

### 3. 交互操作
- **模式切换**：
  - `Esc`：切换到只读模式
  - `:`：从只读模式切换到命令模式
  - `insert/i`：从命令模式切换到编辑模式
- **只读/编辑模式操作**：
  - `h/j/k/l` 或方向键：移动光标
  - `q`：退出程序（仅只读模式）
- **编辑模式额外操作**：
  - 字母/数字/符号：插入字符
  - `Backspace`：删除前一个字符
  - `Delete`：删除当前字符
  - `Enter`：换行
- **命令模式操作**：
  - 输入命令字符
  - `Enter`：执行命令
  - `Esc`：取消命令，返回只读模式

### 4. 命令系统（规划）
- `:q/quit` - 退出
- `:w/write` - 保存（暂存）
- `:wq` - 保存并退出
- `:set number` - 显示行号（规划）
- `:swap single line x y`-交换x与y行的内容
- 其他自定义命令

### 5. 技术栈
- **Rust** + **Ratatui**（UI 框架）
- **Crossterm**（终端事件处理）
- **Color-Eyre**（错误处理）
- **文本缓冲区**：使用 `String` 或后续升级为 `Rope`（性能优化）

### 6. 代码架构
- `main.rs`：程序入口，事件循环
- `app.rs`：应用状态（模式、命令缓冲区、光标位置、文本缓冲区）
- `ui.rs`：界面渲染逻辑
- `event.rs`：事件处理器（线程、Tick、事件转发）
- `update.rs`：业务逻辑更新（按键处理）

## 设计参考
- 参考 Ratatui 官方 JSON 编辑器示例的设计理念
- 借鉴 Vim/Neovim 的模式切换逻辑
- 界面风格：简洁、清晰，使用 Rounded 边框
